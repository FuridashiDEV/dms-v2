# DocFlow Pilot Demo Scenario

Цель: показать DocFlow как pilot-ready enterprise MVP за 3-5 минут без реальных клиентских данных.

## Подготовка

1. Запустить миграции и приложение.
2. Подготовить demo data:

```powershell
.\.venv\Scripts\python.exe manage.py prepare_demo_data --skip-vectors
```

3. Войти под `demo_admin / DemoArchive2026!`.

## Сценарий на 3-5 минут

1. Dashboard: показать количество документов, статус системы и последние действия.
2. Загрузка документа: открыть форму загрузки, показать безопасную валидацию файла и понятные поля карточки.
3. Поиск по смыслу: перейти в документы и выполнить запрос `договор с ИП Фирма на поставку инструментов на 3 млн`.
4. Объяснение результата: показать короткие причины нахождения, фрагмент и связанные документы без технических Qdrant/model details.
5. Карточка документа: открыть `Contract for OCR and AI Search Pilot`, показать версии, AI/OCR статус, workflow, связи и обмен с контрагентом.
6. Evidence report: открыть человекочитаемый доказательный отчет; подчеркнуть, что это технический пакет, не ЭЦП и не юридическое заключение.
7. Роли доступа: войти под сотрудника отдела и показать, что видимость документов ограничена организацией, отделом и выданными доступами.
8. B2B chain: показать исходящий exchange, комментарии, статус ссылки и историю событий.

## Что не показывать как готовое

- SOC2/ISO сертификацию.
- 99-100% точность AI-поиска.
- Полностью production Kubernetes/HA-кластер.
- Реальную ЭЦП или юридическую силу evidence package.
- Реальные клиенты, реквизиты или персональные данные.

## Ручная проверка перед демонстрацией

- Главная страница открывается после логина.
- Список документов не показывает технический мусор обычному пользователю.
- Поиск возвращает ожидаемый договор и связанные документы.
- Evidence report не содержит token, secret, raw payload, server path.
- External portal работает только по актуальной ссылке.
- Mobile viewport не ломает header, cards и tables.
