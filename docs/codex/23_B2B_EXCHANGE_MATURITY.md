# Stage 23 — B2B Exchange Maturity / Усиление B2B-обмена

## Цель этапа

Довести существующий B2B-обмен до более удобного пилотного уровня.

Этот этап должен улучшить уже существующие `DocumentExchange`, `ExchangeEvent`, `ExchangeMessage`, `Counterparty`, `CounterpartyContact`, а не создавать отдельную систему обмена.

## Что нужно улучшить

Добавить или улучшить:

- карточку обмена;
- отображение статуса обмена;
- срок действия ссылки;
- отзыв ссылки;
- повторную отправку;
- историю событий;
- историю сообщений;
- фильтры;
- отображение контрагента;
- отображение контактного лица.

## Карточка обмена

Добавить страницу или улучшить существующее отображение exchange.

На карточке обмена должно быть видно:

- документ;
- направление обмена;
- контрагент;
- контактное лицо;
- статус;
- дата отправки;
- дата открытия;
- дата скачивания;
- дата ответа;
- срок действия ссылки;
- активна ли ссылка;
- история событий;
- сообщения.

## Отзыв ссылки

Добавить возможность отозвать ссылку.

После отзыва:

- портал не должен открывать документ;
- скачивание должно быть запрещено;
- статус должен отражать отзыв;
- должно писаться событие exchange;
- должен писаться audit event.

## Срок действия ссылки

Если срок истёк:

- портал должен показать безопасное сообщение;
- документ не должен скачиваться;
- событие должно быть зафиксировано, если это предусмотрено текущей логикой.

## Права доступа

Пользователь может видеть и управлять только обменами, связанными с доступными ему документами и организацией.

Контрагент через portal token видит только один exchange.

## Чего нельзя делать

- Не добавлять внешние аккаунты контрагентов.
- Не делать поставщицкую сеть.
- Не добавлять электронную подпись.
- Не делать чат в реальном времени.
- Не начинать Stage 24.
- Не обходить текущую token security.

## Тесты

Добавить tests:

1. Карточка обмена доступна авторизованному пользователю с доступом.
2. Пользователь другой организации не видит exchange.
3. Ссылка может быть отозвана.
4. Отозванная ссылка не открывает портал.
5. Истёкшая ссылка не позволяет скачать документ.
6. События и audit пишутся.
7. Сообщения остаются привязанными к exchange.
