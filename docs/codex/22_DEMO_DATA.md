# Stage 22 — Demo Data / Демонстрационные данные

## Цель этапа

Создать качественные демонстрационные данные для показа продукта инвесторам, клиентам и техническим партнёрам.

После запуска demo seed команда должна наполнять систему реалистичными данными для демонстрации:

- организаций;
- отделов;
- пользователей;
- папок;
- документов;
- версий;
- связанных документов;
- ИИ-предложений;
- согласований;
- контрагентов;
- обменов;
- сообщений;
- аудита;
- использования;
- аналитики.

## Текущий контекст проекта

В проекте уже есть DMS, документы, версии, организации, отделы, аудит, usage, import, AI review, workflow, exchange, messages, evidence, analytics.

Нужно создать demo data поверх существующей архитектуры, не создавая отдельную demo-систему.

## Что нужно реализовать

Добавить или обновить management command:

```powershell
python manage.py prepare_demo_data
