# ПУНКТ 7 — IMPORT / MIGRATION LAYER: УДОБНЫЙ ПЕРЕХОД КЛИЕНТА НА ПРОДУКТ

## Цель

Цель этого пункта — добавить слой импорта документов, чтобы клиент мог перейти на продукт постепенно и безопасно.

Продукт не должен требовать от клиента вручную создавать каждый документ.

Нужно поддержать сценарий:

```text
клиент загружает архив / несколько файлов / Excel-реестр
↓
система создаёт ImportBatch
↓
каждый файл отслеживается как ImportFile
↓
успешные файлы превращаются в обычные Document
↓
документы проходят через существующую DMS-логику
↓
при необходимости запускается AI processing
