# ПУНКТ 9 — COUNTERPARTY PORTAL MVP: ВНЕШНИЙ ПОРТАЛ ДЛЯ КОНТРАГЕНТОВ

## Цель

Цель этого пункта — добавить минимальный внешний портал для контрагентов.

После этого пункта организация должна иметь возможность:

```text
выбрать документ
↓
выбрать или создать контрагента
↓
отправить документ по защищённой ссылке
↓
контрагент открывает ссылку
↓
контрагент принимает / отклоняет / комментирует документ
↓
все события фиксируются
