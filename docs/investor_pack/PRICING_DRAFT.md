# Pricing Draft

This is a draft for discussion only. No payment gateway or real invoicing is implemented in the product.

## Possible structure

- Pilot package: fixed pilot setup and support fee.
- Team plan: per organization/month with document and user bands.
- Enterprise plan: custom deployment, security review and support.

## Usage dimensions

- Active users.
- Stored documents.
- AI/OCR processed pages.
- Semantic indexing volume.
- External exchanges.

## Guardrails

- Current product tracks usage and quotas as foundation.
- The system does not hard-block users by quota in the current stage.
- Commercial limits must be validated after first pilot usage data.
