# Limitations and Roadmap

## Current limitations

- Benchmark data is synthetic/semi-real until pilot documents are approved for testing.
- Heavy model benchmarks require prepared local runtime and hardware.
- Qdrant is optional and can degrade to basic search.
- No e-signature or legal certification.
- No hard quota enforcement.
- No payment gateway.
- No fully managed HA production platform.

## Post-pilot roadmap

- Customer-specific benchmark dataset.
- Browser QA with real pilot flows and mobile devices.
- Formal security documentation and DPIA-style review if required.
- LOI, pilot agreement and commercial proposal.
- Search quality tuning from real feedback.
- Production backup/restore drill.
- Optional SSO/SAML, e-signature and deeper integrations after validation.
