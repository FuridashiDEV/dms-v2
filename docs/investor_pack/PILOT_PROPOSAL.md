# Pilot Proposal

## Objective

Run a controlled DocFlow pilot for one organization unit to validate document upload, search, access control, related documents, evidence report and B2B exchange workflows.

## Scope

- 1 organization.
- 2-4 departments.
- 5-20 users.
- 100-1,000 non-sensitive pilot documents or approved synthetic/anonymized samples.
- Optional Qdrant semantic search.
- AI/OCR processing only by approved policy.

## Success criteria

- Users can find known documents faster than manual folder search.
- Access checks prevent cross-department/unauthorized visibility.
- Evidence reports support internal review.
- Search explanations are understandable to non-technical users.
- Admin can monitor usage, cost foundation and failed processing jobs.

## Pilot duration

Recommended 2-4 weeks.

## Out of scope

- Payment processing.
- E-signature.
- Production HA/Kubernetes.
- Deep ERP/1C integration beyond light export/import foundation.
